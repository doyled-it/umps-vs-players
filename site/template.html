How this was measured

Pitch locations and each batter's ABS zone come from Statcast, whose 2026 locations are measured at the middle of the plate, where ABS judges a pitch. Challenges and rulings come from MLB's game feeds. A pitch is a strike if any part of the ball touches the 17-inch-wide zone. Rebuilt this way, the zone matches of the actual ABS rulings, so every called pitch can be graded, not only the challenged ones.

Maps put every batter on one average zone (bottom 19.5 in, top 38.6 in off the ground) while keeping each pitch's exact distance to the nearer edge, which is what ABS uses. Blur comes from fitting each judge's yes-rate against the true distance from the edge. For catchers this uses only ball calls with a challenge left, and allows for catchers passing on some obvious misses.
